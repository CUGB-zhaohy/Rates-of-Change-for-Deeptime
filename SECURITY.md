# Security policy

## Supported version

Security fixes are currently provided for the latest v1.x release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose user data or
enable arbitrary code execution. Contact the maintainers using the developer
contact details in the user manual and include:

- affected version and platform;
- steps to reproduce;
- expected and observed behaviour; and
- any suggested mitigation.

Avoid attaching sensitive input data. Acknowledgement and remediation timing
will depend on severity and reproducibility.
